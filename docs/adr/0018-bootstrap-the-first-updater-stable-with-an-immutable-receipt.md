# Bootstrap the first updater Stable with an immutable receipt

The published Stable `2.0.15` predates Automatic update and therefore cannot truthfully produce previous-Stable-to-candidate evidence. The first updater-capable Stable may enter the Stable channel through one separately named, manually dispatched bootstrap path. This is a one-time trust decision, not an alternative normal promotion mode.

The bootstrap accepts an explicitly reviewed semantic version, release tag, and exact Git commit. It requires the authoritative OSS Stable pointer to remain byte-identical and identify version `2.0.15`; it fresh-installs the official published updater artifacts on the four native targets and consumes the distinct `bootstrap-fresh-install` evidence contract. That evidence explicitly denies any previous-Stable upgrade claim and cannot satisfy the normal real-native update verifier.

Finalization re-reads the legacy Stable pointer, immutable candidate, exact four-target evidence, and absence of any prior receipt. Its first mutation writes a content-digested immutable receipt and verifies the remote bytes. It then re-reads every admission input and the receipt before replacing the Stable manifest as the final mutation. Any complete or partial receipt permanently closes the bootstrap path. Recovery preserves the receipt and evidence; maintainers must investigate and publish a higher version rather than deleting the audit record or retrying with another candidate.

The dedicated workflow uses GitHub's `production` Environment so required reviewers approve the explicit candidate identity. This is a narrow, one-time exception to ADR-0008's rule that Stable admission begins only from the Release `published` event: the candidate must still be an existing published Release, but an administrator explicitly dispatches bootstrap after review. Normal published-release promotion and `--require-real-native` remain unchanged. Once an updater-capable Stable exists, every later promotion must use the normal previous-Stable update gate.
