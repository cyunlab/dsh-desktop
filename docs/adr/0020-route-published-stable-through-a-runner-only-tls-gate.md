# Route published Stable through a runner-only TLS gate

Normal Stable promotion validates the exact published previous Stable rather than a source rebuild, so its compiled production endpoint cannot be replaced for testing. Native update smoke therefore installs a one-run runner CA and exact-host routing gate, holds the real Stable manifest request, restores the original routing before replying with the byte-exact isolated candidate manifest, and lets the subsequent package request resolve to immutable OSS normally. It proves the production normal close/quit installation path plus separate manual relaunch; it does not mutate Stable, rebuild the baseline, add a production automation backdoor, or claim that the explicit Restart UI and negative/unit paths were observed by this lifecycle. Every runner trust/routing mutation is scoped to the exact update hostname and must be reversed even when the smoke fails.
