# Route published Stable through a runner-only TLS gate

Normal Stable promotion validates the exact published previous Stable rather than a source rebuild, so its compiled production endpoint cannot be replaced for testing. Native update smoke therefore installs a one-run runner CA and exact-host routing gate, holds the real Stable manifest request, restores the original routing before replying with the byte-exact isolated candidate manifest, and lets the subsequent package request resolve to immutable OSS normally. It proves the production normal-window-close installation path plus separate manual relaunch; it does not mutate Stable, rebuild the baseline, add a production automation backdoor, or claim that the explicit Restart UI and negative/unit paths were observed by this lifecycle. Every runner trust/routing mutation is scoped to the exact update hostname and must be reversed even when the smoke fails. The root helper owns an isolated process group, handles control-channel EOF and termination signals, and is forcibly reaped under a bounded privileged cleanup if its graceful close fails.

On macOS, the published v2.1.5 baseline predates the later `ExitRequested` orderly-shutdown handler, so an application Quit cannot prove its staged installer path. A repository-owned Swift helper instead requires already-authorized Accessibility, validates the exact PID and bundle identifier, requires exactly one main window, and presses that window's native close button. It makes no TCC mutation. Across all platforms the harness records the Host listener process tree, requires every saved PID to exit, enumerates the exact installed Desktop source to rule out a new-PID automatic relaunch, and only then performs the explicit candidate launch.
